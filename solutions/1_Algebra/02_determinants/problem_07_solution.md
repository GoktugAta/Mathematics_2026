# Problem 7 Solution

We are given that A is a 3 × 3 matrix and:

```math
\det(A)=-4.
```

### 1. Computing det(2A)

For an n × n matrix, multiplying the entire matrix by a scalar k multiplies its determinant by kⁿ. Therefore:

```math
\det(2A)=2^3\det(A)=8(-4)=\boxed{-32}.
```

### 2. Computing det(Aᵀ)

Transposing a matrix does not change its determinant:

```math
\det(A^T)=\det(A)=\boxed{-4}.
```

### 3. Computing det(A²)

The determinant of a product is the product of the determinants:

```math
\det(A^2)=\det(A)\det(A)=(-4)^2=\boxed{16}.
```

### 4. Computing det(−A)

Since A is a 3 × 3 matrix:

```math
\det(-A)=(-1)^3\det(A)=(-1)(-4)=\boxed{4}.
```
