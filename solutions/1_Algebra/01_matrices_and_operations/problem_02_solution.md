# Problem 2 Solution

### 1. Addition ($A + B$)
$$
A + B = \begin{pmatrix} 5 & 0 \\ -1 & 8 \end{pmatrix}
$$

### 2. Subtraction ($A - B$)
$$
A - B = \begin{pmatrix} -3 & 4 \\ -1 & -2 \end{pmatrix}
$$

### 3. Scalar Multiplication and Combination ($3A - 2B$)
$$
3A - 2B = \begin{pmatrix} -5 & 10 \\ -3 & -1 \end{pmatrix}
$$

### 4. Explanation
Matrix addition is only possible for matrices of the same size because addition is performed element-by-element (entry-by-entry). Each element in the first matrix must have a corresponding element at the exact same row and column position in the second matrix.
