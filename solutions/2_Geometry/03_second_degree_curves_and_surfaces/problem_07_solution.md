# Exercise 7. Classifying a Second-Degree Equation

## Question

Determine the type of object described by:

1. 4x^2+9y^2=36.
2. x^2-y^2=1.
3. x^2-4y=0.
4. x^2+y^2+1=0.

In the last case, explain why there are no real points.

## Solution

### 1. The equation 4x^2+9y^2=36

Divide by 36:

```math
\frac{x^2}{9}+\frac{y^2}{4}=1.
```

Both squared terms have positive coefficients, and the denominators are different. Therefore, this is an ellipse centered at the origin.

Its semiaxis lengths are

```math
\boxed{3\text{ horizontally},\qquad 2\text{ vertically}}.
```

The major axis is horizontal because the larger denominator is under x^2.

### 2. The equation x^2-y^2=1

The squared terms have opposite signs, so this is a hyperbola centered at the origin.

Since the x^2 term is positive, its branches open left and right. Its vertices and asymptotes are

```math
\boxed{\text{Vertices }(\pm1,0),\qquad
\text{asymptotes }y=\pm x}.
```

### 3. The equation x^2-4y=0

Rearranging gives

```math
x^2=4y.
```

Only x is squared, while y appears to the first power. This is a parabola with vertex (0,0).

Because

```math
y=\frac{x^2}{4}\geq0,
```

it opens upward. Its axis of symmetry is x=0.

### 4. The equation x^2+y^2+1=0

Rearranging gives

```math
x^2+y^2=-1.
```

For real x and y, both squares are nonnegative:

```math
x^2+y^2\geq0.
```

Their sum cannot equal -1. Equivalently,

```math
x^2+y^2+1\geq1>0.
```

Therefore,

```math
\boxed{\text{The real solution set is empty}}.
```

Although the equation resembles a circle equation, it does not describe a real circle because its squared radius would be negative.
